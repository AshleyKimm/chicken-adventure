# ChickenAdventure
Chicken Adventure Game

Once the game starts, the user uses the arrow keys (left and right) to move the chicken.

If the chicken touches the water drops - its life reduces by 1.
The chicken can speed up by collecting the beans.
The goal is to collect as many eggs as possible before the three lives get used up!

## Tools & Frameworks
- Eclipse IDE
- Scene Builder
- Java
- **Claude is only used for building the web version for demos.**

## Play in the browser

A web version (an HTML/JavaScript port of the JavaFX game with the same game logic) is in [`docs/`](docs/) and is published with GitHub Pages:
https://ashleykimm.github.io/chicken-adventure/

To run it locally, serve the folder (e.g. `python -m http.server` inside `docs/`) and open http://localhost:8000.
